# Contributing

Thanks for helping improve Tenant Meter. Please open an issue before starting a large change so we can agree on its scope. For a small fix, a pull request is fine.

1. Use Node.js 24 or newer.
2. Add a test for behavior changes in `test/`.
3. Run `npm test` before opening a pull request.
4. Explain the use case, behavior change, and any migration needs in the pull request.

Keep the core dependency-free and preserve tenant isolation and idempotent retries. Please do not add third-party usage or contributor claims to the README unless there is public evidence for them.
